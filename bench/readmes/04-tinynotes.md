# tinynotes

Notes in plain Markdown files, searchable from the terminal. No database, no sync service.

## Install

    pip install tinynotes

## Quick start

    tn new "Standup ideas"
    tn search standup

Notes live in `~/notes`. Change it with `TN_DIR`.

## Why

I wanted grep, but with titles and tags.

## Status

Works on Linux and macOS. Windows is untested. There are no tests yet.
