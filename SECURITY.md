# Security

## Reporting a vulnerability

Open a private security advisory on this repository (Security → Advisories → Report a vulnerability). Please do not open
a public issue.

Never include keys, cookies or identities in a report. Describe the request and the response instead.

## Scope

In scope: the deployed app and its API routes, the scripts in `scripts/`, and `winnow-kit`.

Out of scope: Flagsmith, Groq and Vercel themselves, and rate limits on a free LLM tier.
